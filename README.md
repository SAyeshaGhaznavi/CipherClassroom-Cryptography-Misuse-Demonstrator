# CipherClassroom — Member C Frontend

React + TypeScript + Vite frontend for the Information Security proposal **CipherClassroom: Cryptography Misuse Demonstrator**. This project is independently runnable without Docker, a backend, or a database.

## Requirements
- VS Code
- Node.js 20.19+ or 22.12+ (Node 22 LTS recommended)
- npm

## Run on Windows (VS Code terminal, PowerShell)

```powershell
cd frontend
npm install
npm run dev
```

Open the local URL displayed by Vite (normally `http://localhost:5173`). Choose **Operator** or **Administrator** for the UI demonstration. `Viewer` is a read-only demo role.

To check the production build:

```powershell
npm run build
```

To preview the built frontend:

```powershell
npm run preview
```
